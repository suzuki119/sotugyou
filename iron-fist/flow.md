# IRON FIST ゲームの流れ（スタート → チュートリアル → 戦闘）

実装（`src/main.js` の状態遷移、`src/game/gameManager.js`）に基づく現状の流れ。

## 全体の状態遷移

```
START ─▶ CAMERA_PERMISSION ─▶ CALIBRATION ─▶ TUTORIAL ─▶ READY ─▶ PLAYING ─▶ BOSS ─▶ CLEAR ─▶ RESULT
 ▲        (初回のみ)           (初回のみ)      (6ステップ)  (3秒)    (ザコ戦)   (ボス戦)    │         │
 │                                                                     │         │        GAME_OVER ─┘
 │                                                              HAND_LOST (手を見失うと一時停止。両手グリップで復帰)
 └──────────────────────────── 「タイトルへ」 ◀──── RESULT ───▶ 「リトライ」→ READY
```

## 1. スタート画面（START）

- タイトル「IRON FIST」と「スタート」ボタン（Enter でも可）。BGM / 効果音の音量スライダーあり。
- 背景はロボットをタイトル用カメラで外から映す演出。BGM は `tutorial` 曲。
- 「スタート」を押したあとの分岐：→この時点で戦闘画面（操縦桿やレバーなど）は出す
  - キーボード操作（開発用）→ 直接 READY へ
  - カメラ未起動 → カメラ許可画面へ（カメラの許可やチュートリアルは、humanの画面で行う）
  - カメラ起動済み → キャリブレーション済みなら READY、未なら CALIBRATION

## 2. カメラ許可（CAMERA_PERMISSION）※初回のみ

- 「カメラで両手の動きを読み取る」旨の説明（映像は端末内のみ処理・保存/送信しない・ゲーム中は映像を表示しない）。
- 「カメラを開始」→ 起動成功で CALIBRATION へ。失敗時はエラー表示と「もう一度試す」。

## 3. キャリブレーション（CALIBRATION）※初回のみ

- ロボットが片膝をついてハッチを開け、乗り込みを待つ演出。
- 「両手で操縦桿を握ってください」：右手はボールスティックを上から包む、左手はグリップを握る構えで静止。
- 手の骨格プレビューと左右の検出表示。**両手グリップを約2秒（`calibrationMs`）保つ**と基準位置を記録。途中で崩れるとやり直し。
- 記録するもの：両手の位置・大きさ、右手の基準の傾き（ボールスティック）、左手の基準の指の向き。
- 完了 → TUTORIAL へ。

## 4. チュートリアル（TUTORIAL）

- 右上に、モニター風の「OPERATOR LINK」パネル（オペレーターの顔画像＋説明文＋進行バー）を表示。搭乗モード表示はその下へ移動。
- 各ステップの条件を満たすと進行バーが約1.2秒で満タンになり、次のステップへ。
- 顔画像は、通常は `human_normal`、条件達成中（バーが進んでいる間）は `human_good`。
- スキップ：Enter で READY へ。（画面に表示しておくこと）

| # | タイトル | 内容 | 進む条件 |
|---|----------|------|----------|
| 1 | 右手で照準 | 右手を握って左右に動かし照準を動かす（上下は自動で敵に合う。画面端に寄せると機体が旋回） | 照準が中心から一定以上動く |
| 2 | 親指で射撃 | ボールを握ったまま親指を閉じている間、連射。離すと止まる | 射撃入力が入り、かつ的で雑魚敵に当たる |
| 3 | 左手で移動 | 左手を握り、手首を曲げて指を下で前進、上で後退。左右で横移動 | 移動して目的地点の黄色く光るゾーンまで移動 |
| 4 | ロボットから降りる | 両手をパーにして少し待つと降りて共闘モードに | 共闘モードになる |
| 5 | 剣で斬る | 右手をすばやく振ると剣で斬撃を飛ばす。左手は左右で旋回、前後で移動 | 共闘中に斬撃を1回出す |
| 6 | ロボットに乗る | もう一度両手をパーにして搭乗モードに戻る | 搭乗モードになる |

- チュートリアル中も実際に操作でき（`practice` 更新）、BGM は `tutorial` 曲のまま。
- 全6ステップ完了 → READY へ。

## 5. 戦闘開始（READY）

- ゲームをリセットし、**3 → 2 → 1** のカウントダウン（3秒）。この間も操作は可能（練習）。
- BGM は `battle` 曲に切り替わる。3秒後に PLAYING へ、「GO!」を表示。

## 6. ザコ戦（PLAYING）

- 闘技場で敵（ドローン65% / ウォーカー35%）が **2.5秒ごと**に出現。同時に存在できるのは最大5体。最初の1体で門が開く。
- 操作は搭乗モード（右手で照準・射撃、左手で移動、画面端で旋回）が基本。
  - 銃はエネルギー制：射撃で消費し、撃たないと回復。0になるとオーバーヒートで、一定量回復するまで撃てない。
  - 照準にはエイムアシスト（近くの敵に吸い付く）。
- **両手パー約0.5秒で搭乗 ⇄ 共闘を切り替え**。共闘中はロボットが自分で歩き、敵を撃つ・殴る。プレイヤーは剣で戦う。
- HUD：照準、手の状態、HP、EN、スコア/タイム、モード表示（切り替え進行バー付き）、手の骨格（H キーで切り替え）。
- **両手を約1.5秒見失うと一時停止（HAND_LOST）**。BGM が小さくなり、両手をグリップすると復帰。
- 敵の弾を受けると HP 減少（最大100）。HP が 0 になると GAME_OVER。
- **ザコを12体倒す、または開始から120秒経過**でボス戦へ。

## 7. ボス戦（BOSS）

- 「WARNING」を表示し、BGM が `boss` 曲に。ボスが門の正面から出現。ザコの出現は止まる。
- 画面上部にボスの HP バー。操作・モード切り替えは PLAYING と同じ。
- ボスを倒しきる → CLEAR。HP が 0 → GAME_OVER。

## 8. 終了とリザルト

- **CLEAR**：「MISSION CLEAR」、ロボットが勝利ポーズ（外から映す演出）。
- **GAME_OVER**：「GAME OVER」、ロボットが倒れる演出。
- 約2.5秒後に **RESULT** へ。BGM は無音。
- リザルト画面：スコア（撃破数 + 残りHP + 早いクリアのボーナス）、タイム、撃破数、残りHP。
- 次の行き先：
  - **リトライ**（ボタン / Enter / R、または両手グリップを2秒握り続ける）→ READY へ（キャリブレーション・チュートリアルは省略）
  - **タイトルへ**（ボタン / T）→ START へ
